## 4 · The five device classes (one site, five relative layouts)
- **D1 Phone (≤ 640px)** — nav: Logo bar + hamburger → full-screen overlay drawer; hero: Poster stack: eyebrow → headline → copy → stacked CTAs → visual below; features 1-col; footer: Stacked groups, tap-to-open.
- **D2 Tablet (641 – 1024px)** — nav: Condensed bar: logo + 3 key links + CTA (rest stays in drawer); hero: Centered composition, visual below at ~72% width; features 2-col; footer: 2-column grid.
- **D3 Laptop (1025 – 1440px)** — nav: Full inline nav: all links + CTA inline; hero: Split 55 / 45: text left, visual right; features 3-col; footer: 3-column grid.
- **D4 Desktop (1441 – 1920px)** — nav: Full inline nav, container-capped; hero: Split 55 / 45 + stats row unlocks beneath; features 4-col; footer: 4-column mega footer + newsletter.
- **D5 Ultra / TV (≥ 1921px)** — nav: Centered ceremonial nav, letter-spaced; hero: Cinematic full-bleed: monumental centered type over ambient stage; features 5-col; footer: 4-column centered, ambient backdrop.
These are structural re-arrangements, not zoom levels. Built from relative units only
(%, fr, clamp(), rem, aspect-ratio).

## 5 · C.R.A.P. audit (Robin Williams)
- **Contrast** — every ink/background pair measured against WCAG targets (table above).
- **Repetition** — one spacing scale, one type scale, tokenised colour roles, reused everywhere.
- **Alignment** — all content sits on the container grid of its device class; nothing nudged by eye.
- **Proximity** — related blocks grouped, section rhythm a fixed multiple of the spacing scale.
